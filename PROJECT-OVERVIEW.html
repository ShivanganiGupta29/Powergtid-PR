🚀 Deploy to GitHub in 3 Easy Steps

Create GitHub Repository

Go to GitHub.com → Click "+" → "New repository" → Name it powergrid-pr-system → Create

Upload Your Files

Easy way: Click "Upload files" and drag the entire folder
Git way: Use the commands in DEPLOYMENT.md

Enable GitHub Pages

Settings → Pages → Source: main branch → Folder: / (root) → Save
Your site will be live in 1-2 minutes!

🌐 Your site will be at:
https://YOUR-USERNAME.github.io/powergrid-pr-system/

🎨 Easy Customization

Change Colors:

Edit the CSS variables at the top of css/main.css:

:root { --primary-color: #003366; /* Your brand color */ --success-color: #28a745; /* Success messages */ --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%); }

Add Materials:

Edit the materialCatalog array in js/data.js

Modify Features:

Edit functions in js/app.js - well-commented and organized
